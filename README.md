# 🩺 NorthBridge Health Services — SLA Breach Prediction

> **Machine Learning Solution for Predicting Service Level Agreement (SLA) Breaches**
> Built for NorthBridge Health Services Ltd — Manchester, United Kingdom

---

## 📋 PROJECT OVERVIEW

NorthBridge Health Services manages customer service tickets across multiple healthcare clients. With rising ticket volumes, manual SLA monitoring became unreliable — leading to missed deadlines, financial penalties, and client dissatisfaction.

**This project builds an end-to-end machine learning pipeline to:**
- ✅ Centralise operational ticket data
- ✅ Monitor SLA performance in real-time
- ✅ **Predict which tickets will breach their SLA deadline BEFORE it happens**
- ✅ Identify key factors driving SLA breaches
